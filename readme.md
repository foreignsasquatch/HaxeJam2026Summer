# HaxeJam 2026: Summer Jam 
> NOTE: **NO LLMs/GEN AI TOOLS WERE USED IN ANY PART OF THE PROCESS.**

A small first person shooter made for the HaxeJam 2026: Summer Jam.
This is my first time doing some 3D outside of experiments, hopefully
it turns out good. If you're compiling this and want to try the editor,
you can run it by `./Editor content/level1/data.json`.
